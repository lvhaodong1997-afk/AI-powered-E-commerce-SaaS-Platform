ClipForge Studio

Data Deletion

Last updated: August 6, 2026

How to request deletion

Users can request deletion of ClipForge Studio account data, uploaded media, generated videos, captions, project records, and TikTok authorization records by emailing shangan@zswo.net.

What to include

Use the subject line ClipForge Studio Data Deletion Request. Include the account email, workspace name if available, and the type of data to delete. Do not include passwords or payment information in the request.

TikTok authorization removal

Users may revoke TikTok access from TikTok account settings. Users may also request removal of TikTok authorization records stored by ClipForge Studio through the same support email.

Processing

ClipForge Studio will review deletion requests, verify account ownership when needed, and remove eligible data from active systems. Some records may be retained when required for security, legal compliance, billing, abuse prevention, or audit history.

Contact

For account deletion, media deletion, TikTok authorization removal, or privacy questions, contact shangan@zswo.net.
