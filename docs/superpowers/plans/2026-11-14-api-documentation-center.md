# API 文档中心实施计划

## 已确认范围

用户已批准 P0、P1，并要求同步远端、完成开发、提交推送和服务器部署。采用当前 Vue 3/Vite/Element Plus，新增公开 `/api-docs`；不改变后端鉴权、积分和任务接口，不新增表，不提交其它本地改动。

## 设计与交付

- 面向第一次接入的用户，中文教程配合原始字段名；白色阅读区、深色代码区、蓝绿色接口标记，左侧分组目录、右侧固定语言切换。桌面双栏、手机可折叠目录。使用现有品牌字体，无额外图标或 UI 依赖。
- OpenAPI 为接口字段数据源；指南解释流程和规则；静态资料生成脚本复制白名单文档、示例、Postman 和契约供下载，提供 `--check` 检查生成结果。页面不访问账号数据，不执行收费请求。
- 出片与 TikTok 发布明确分开鉴权；登录验证码按原策略处理；出片 POST 不盲目重试；查询有限轮询；保存 taskId 并可续查；下载不转发平台 Token。

## 执行任务

1. 同步 `origin/main`，只快进或保留修改地合并，不覆盖用户文件。记录基础提交。
2. 先测试后实现 Python/Node 完整出片样例，包含资源选择、业务错误、Token 刷新、提交记录、超时、轮询与流式下载。测试使用本地 HTTP 服务，不消耗积分。
3. 更新平台总文档及 OpenAPI，补充登录、租户、7 个出片接口；修正 HMAC security 为同一对象内的 AND 要求，保留原发布端点。新增快速开始、规则、错误、签名教程及 Postman 模板。
4. 新增静态资料生成脚本、契约测试和页面数据。先验证缺失契约/下载文件会失败，再生成并验证。
5. 新增 Vue 文档页、公开路由与白名单；首页和管理页文档入口；搜索、锚点、语言切换、复制、资料下载、移动端布局。
6. 运行契约和示例测试、既有公开页面测试、聚焦格式/语法及前端生产构建；浏览器验证桌面/手机、导航、搜索、复制和下载。请求独立代码复核，处理实质问题。
7. 只提交本次文件，同步远端 main 后推送 main，再次核对远端提交，从干净的远端最新源码构建。检查并同步服务器当前版本，发布前端和文档资产，保留后端、生产配置、旧资源与回滚版本；验证公网页面、下载、API 鉴权和原业务入口。

## 验收命令

从前端目录运行 `node --test tests/api-docs*.test.cjs`、`node tests/public-homepage-route.test.cjs`、`node scripts/build-api-docs.mjs --check` 和 `pnpm build:prod`。示例测试从仓库根目录运行 Python unittest 及 Node test（具体文件随任务落地）。生产部署只执行静态内容发布，不创建真实生成或外部发布任务。
