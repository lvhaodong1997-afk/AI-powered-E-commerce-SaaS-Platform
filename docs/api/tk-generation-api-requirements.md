# 出片能力 API 对接需求说明

> 版本：1.0 · 日期：2026-11-11
> 用途：自动化出片工具接入本平台、实现「不点网页即可完整出片」所需的 API 能力清单
> 范围：**千川上传与入计划不在本清单内**（该部分已有现成接口）

---

## 1. 目标与范围

工具按实际出片顺序，依次调用 API 完成：鉴权 → 查积分 → 选素材库 → 选音色 → 选 BGM → 提交生成任务 → 查进度 → 下载成片。全流程不得依赖网页点击，所有失败必须可读、不得静默降级或静默失败。

请确认以下能力由哪一层提供：**现有开放 API**、**新增生成类开放接口**，或其他方式；并据第 5 节给出接口清单与字段约定。

---

## 2. 必需能力清单（按出片顺序）

| # | 环节 | 需求 | 期望返回 / 约束 |
| --- | --- | --- | --- |
| 1 | 登录与账号 | 使用已有账号完成鉴权，并保持会话有效 | Token、有效期、续期方式；会话过期可自动续期 |
| 2 | 查积分 | 返回当前可用积分；积分不足时明确报错 | 余额数值 + 独立错误码与所需积分数；**不得静默失败** |
| 3 | 查素材库 | 列出可用素材库，并能指定使用「芒果干」 | 至少返回库 ID、名称、标签、素材数量；可按名称检索 |
| 4 | 查配音音色 | 列出可用音色，便于按人群选择 | 至少返回音色标识、显示名、是否可用；需能过滤不可用项 |
| 5 | 查已上传 BGM | 列出「我的上传」曲目，**至少返回文件名** | 曲目 ID、文件名、时长、可访问地址；只列本人/本租户上传 |
| 6 | 提交生成任务 | 一次调用传入第 3 节全部参数 | 返回任务号；参数被拒或不生效时必须报错或回显实际值 |
| 7 | 查询任务进度 | 返回任务号、当前步骤、是否完成或失败 | 状态、当前步骤、进度；失败时返回可读原因与错误码 |
| 8 | 下载成片 | 任务完成后给出可下载的成片文件或地址 | 带过期时间的下载地址 + 建议文件名；便于按约定命名保存 |
| 9（加分） | 按标签抽画面 | 按场景、产地、口感等业务标签控制画面方向 | 若不支持，工具将从「芒果干」库自行全库随机混剪 |

---

## 3. 生成任务必须一次传入的参数

| 项目 | 要求 |
| --- | --- |
| 完整口播正文 | 原文传入，平台不改写、不拼接人群画像或结构说明 |
| 翻译 | 关闭 |
| 目标地区 | 中国大陆，需**独立字段**并在任务详情回显，不能仅由语言推断 |
| 素材库 | 第 3 项查得的库 ID |
| 配音音色 | 第 4 项选定的音色标识 |
| BGM | 第 5 项选定的曲目 ID |
| BGM 音量 | 约 40%，**原样生效并在任务详情回显实际值** |
| 智能字幕 | 开启；特大字号、标准白字黑边、智能避让、关键词高亮、逐字卡点 |
| 成片时长 | **严格跟随完整口播结束即停**；不强制 15／29／35 秒，口播短于设定值时也不补画面 |
| 画幅与帧率 | 竖屏 1080×1920、30 帧 |

---

## 4. 技术要求（避免静默降级）

1. **积分不足**：返回独立错误码与所需积分数，任务不创建，不得静默失败。
2. **BGM 音量**：传入值必须原样生效；若发生钳制、降级或默认版本差异，必须在响应中回显实际生效值。
3. **时长**：提供「跟随口播音频」的时长模式，成片时长等于口播音频时长，不得以设定最小时长补齐画面。
4. **目标地区**：提供独立字段并在任务详情回显。
5. **BGM 列表**：返回原始文件名；「我的上传」应有明确的来源区分，不与系统曲库混列。
6. **字幕**：逐字卡点等能力若因时间轴质量降级，必须在任务结果中返回降级状态与原因，不能只看开关是否开启。
7. **任务结果**：状态、当前步骤、失败原因、错误码必须可读；建议提供失败重试与排队任务取消。
8. **成片地址**：带过期时间的签名地址，含建议文件名；地址失效后可重新签发。
9. **回调（建议）**：任务完成／失败时推送结果，失败回调携带错误码与原因。
10. **鉴权与计费**：按调用方隔离数据与积分，任务号使用不可枚举 ID，写操作支持幂等键。

---

## 5. 建议的接口清单

建议沿用现有开放 API 的签名鉴权、幂等键、回调与调用方隔离模型，新增一组生成类接口：

| 方法 | 建议路径 | 对应需求 |
| --- | --- | --- |
| `GET` | `/open/v1/generation/credits/balance` | 2 查积分 |
| `GET` | `/open/v1/generation/material-libraries` | 3 列出素材库 |
| `GET` | `/open/v1/generation/material-libraries/{id}/tags` | 9 列出可用画面标签（加分项） |
| `GET` | `/open/v1/generation/voices` | 4 列出音色 |
| `GET` | `/open/v1/generation/bgm?sourceType=USER` | 5 只列「我的上传」 |
| `POST` | `/open/v1/generation/tasks/precheck` | 6 提交前预检（积分、素材、字幕可行性） |
| `POST` | `/open/v1/generation/tasks` | 6 一次传入全部生成参数 |
| `GET` | `/open/v1/generation/tasks/{taskId}` | 7 任务号、状态、当前步骤、失败原因 |
| `GET` | `/open/v1/generation/tasks/{taskId}/result` | 8 成片下载地址、建议文件名、字幕降级原因 |
| `POST` | `/open/v1/generation/tasks/{taskId}/retry` | 7 失败重试 |
| `POST` | `/open/v1/generation/tasks/{taskId}/cancel` | 7 取消排队任务 |
| `POST` | `/open/v1/generation/tasks/{taskId}/publish` | 打通现有发布接口，成片直发 |

`POST /tasks` 建议支持的最小字段集：`libraryId`、`promptText`、`translationEnabled`、`targetRegion`、`voiceCode`、`bgmAssetId`、`bgmVolume`、`subtitle`（含字号／样式／避让／关键词高亮／逐字卡点）、`durationMode`、`materialTags`、`externalRequestId`、`Idempotency-Key`。

---

## 6. 需要确认的问题

1. 上述 9 项是走**现有开放 API**、需要**新增生成类开放接口**，还是其他接入方式？
2. 鉴权方式与账号归属：使用已有账号时，Token 有效期、自动续期与权限范围由谁维护？
3. BGM 音量 40% 能否原样生效并在详情回显？是否存在默认版本差异？
4. 能否保证「成片时长 = 完整口播结束」，口播短于设定时长时不补画面？
5. 「我的上传」列表是否返回原始文件名？下列人群曲池当前是否已按命名入库？
6. 是否提供按业务标签（场景／产地／口感）抽画面的能力？若否，是否接受工具侧全库随机混剪作为兜底？

---

## 7. 验收口径

使用已有账号，按第 2 节顺序一次性跑通：查积分 → 指定「芒果干」库 → 选定音色与同人群 BGM → 提交含全部参数的生成任务 → 轮询至完成 → 下载成片并按约定文件名保存。过程中无需任何网页操作；任一环节失败均可读到明确原因。

## 附录 A：工具侧选取规则（供理解调用逻辑，不要求接口实现）

**音色优先级**：精致妈妈、新锐白领 → 「温柔学姐」；资深中产 → 优先「沉稳高管」，不可用则「温柔学姐」；小镇青年 → 优先「霸道青年音色-beta」，不可用则「温柔学姐」。

**BGM 人群池**：仅在同人群内随机选一首，音量约 40%，不借用其他人群曲目。

| 人群 | 曲池命名 |
| --- | --- |
| 精致妈妈 | 温馨居家 01–12 |
| 资深中产 | 品质感 01–11 |
| 新锐白领 | 办公室下午茶 01–12 |
| 小镇青年 | 活泼日常 01–11 |

> 曲池曲目依赖运行时数据命名，请确认当前库中是否已按此命名；工具侧按名称前缀匹配并限定同池随机。
